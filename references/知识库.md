## 一、番茄平台规则

### 1.1 签约机制
| 规则 | 说明 |
|------|------|
| 签约机会 | 每本书3次—2万字/5万字/8万字各可申请一次 |
| 评估内容 | 安全审核（合规性+格式）+ 编辑评估（内容质量+商业潜力） |
| 永久锁死 | 三次编辑评估均失败 → 该作品永久失去签约资格 |
| 建议策略 | 写到3万字再提交首次申请，前3章至少打磨3遍 |

### 1.2 推荐机制
| 阶段 | 时长 | 规则 |
|------|------|------|
| 验证期 | 7天 | 书架比+追更比均需≥35%，不达标直接淘汰 |
| 首秀期 | 21天 | 必须日更6000字，禁止修改内容，断更一天中断 |
| 竞争强度 | 日均5600+部新书 | 爆款率不足0.8% |
| 核心指标 | 完读率/追读率/留存率/书架率 | 算法只看这四个数据 |

### 1.3 2026年严打重点
- 滥用AI工具批量生成、拼凑内容
- 内容缺乏原创性与完整性、整体质量低劣
- 语言生硬、内容空洞的"AI水文"
- 允许AI辅助，严打纯AI灌水

## 三、爆款公式模板

### 3.1 书名公式
**通用公式：热词 + 身份 + 冲突 + 爽点**

**男频三套：**
1. 重生/穿越 + 年代 + 金手指 + 终极目标
   - 例：《重生1998：我靠系统成世界首富》
2. 被XX后 + 隐藏身份 + 曝光
   - 例：《被退婚后，我战神身份曝光了》
3. 开局XX + 我XX + 制霸/无敌
   - 例：《开局觉醒SSS天赋，我横推无敌》

**女频三套：**
1. 穿成XX + 我把XX + 虐哭了/玩坏了
   - 例：《穿成恶女后，我把男主虐哭了》
2. 重生 + 时间 + 我开启了 + XX模式
   - 例：《重生1988：我开启了女首富模式》
3. XX后 + 大佬身份 + 藏不住了
   - 例：《离婚后，我的隐藏身份藏不住了》

### 3.2 简介三句半公式
```text
第一句：前世/现状有多惨（拉仇恨）
第二句：重生/觉醒后干了什么狠事（给爽点）  
第三句：某个反派还不知道主角有什么底牌（留悬念）
半句：一句情绪喊话（让读者代入）
```

### 3.3 黄金三章铁律
| 章节 | 核心任务 | 字数范围 | 关键动作 |
|------|---------|---------|---------|
| 第一章 | 抛出核心冲突 | 前300字必须出冲突 | 主角被欺负/羞辱/背叛/追杀 → 结尾留钩子（金手指要来了）|
| 第二章 | 展现金手指 | 前700字内亮金手指 | 系统激活/重生记忆解锁/隐藏身份显露/神器到手 |
| 第三章 | 首次打脸 + 明确短期目标 | 1000字内打脸 | 小反派被怼/被揭穿/被反杀 → 结尾抛出更大悬念 |

### 3.4 每章标准结构
```
开头(0-200字)：直接进剧情，不写景/不写心理/不铺垫
冲突升级(500-800字)：矛盾推进
反转/小爽点(300-500字)：打脸/展现金手指
章末钩子(100-200字)：信息钩/情绪钩/悬念钩轮换使用
目标章节长度：1500-2500字
```

### 3.5 钩子类型库
| 类型 | 公式 | 示例 |
|------|------|------|
| 信息钩 | "他看到了那个名字" | "门牌上写的不是公司名，是一个墓地的地址" |
| 情绪钩 | "所有人都跪了下去" | "门开了。会议室里五十二个人，没有一个站着的" |
| 悬念钩 | "明天她才知道自己惹了谁" | "她以为这就完了？明天开盘，她的公司会蒸发三十亿" |
| 反转钩 | "那个人笑了" | "他看完信，笑了。然后把打火机凑了上去" |

## 四、爽点工程规范

### 4.1 爽点密度标准
| 级别 | 频率 | 强度 | 不能超过的间隔 |
|------|------|------|--------------|
| 小爽 | 每章至少1次 | 打脸/震惊/获得/装弱反杀 | 不能连续2章没有 |
| 中爽 | 每3章至少1次 | 碾压敌人/身份曝光/能力突破 | 不能超过3章 |
| 大爽 | 每10章至少1次 | 阶段性高潮/大反转/终极打脸 | 不能超过10章 |

### 4.2 爽点类型速查
| 类型 | 适用性别 | 典型场景 | 写法要点 |
|------|---------|---------|---------|
| 打脸爽 | 男女通用 | 反派嚣张 → 主角碾压式反杀 | 先让反派嚣张到极致，一章内打完 |
| 成长爽 | 男频 | 能力/财富/等级可视化的增长 | 给清晰的能力条，让读者看到数字往上涨 |
| 掉马甲爽 | 女频 | 隐藏身份被揭穿，众人震惊 | 铺垫要长，掉的那一刻要炸 |
| 暴富爽 | 男频 | 彩票/鉴宝/投资一夜暴富 | 必须有对比：昨天还在吃泡面 |
| 复仇爽 | 女频 | 前世害我的人一个一个付出代价 | 每个反派的报应要与其罪行对等 |
| 身份反差爽 | 男女通用 | 被瞧不起的人其实是隐藏大佬 | 反差越大越爽 |

### 4.3 憋屈上限
- 绝对禁止连续憋屈超过2章
- 虐完必须立刻爽——当天给补偿，不隔夜
- 如果一个大反派要铺垫3章，中间每章要穿插小爽点（揍小兵/收小弟/获得宝物）

## 五、去AI化全量标准

### 5.1 10维度AI味检测
| 维度 | 满分 | 及格线 | AI味典型表现 |
|------|------|--------|-------------|
| D1 模板词密度 | 10 | ≥8 | "不仅是...更是..."、"在这个...的时代" |
| D2 段落结构 | 10 | ≥8 | 每段3-5句，整齐得像军训 |
| D3 情绪描写具体度 | 10 | ≥8 | "感到愤怒"、"心中一阵难过" |
| D4 对话自然度 | 10 | ≥8 | 所有人说话像同一个人 |
| D5 句式节奏 | 10 | ≥8 | 全是陈述句，没变化 |
| D6 信息密度 | 10 | ≥8 | 大段内心独白无推进作用 |
| D7 过渡自然度 | 10 | ≥8 | "与此同时"、"另一方面"滥用 |
| D8 人称统一 | 10 | ≥8 | 视角来回跳 |
| D9 标点语气 | 10 | ≥8 | 滥用感叹号制造假情绪 |
| D10 原创性 | 10 | ≥8 | 拼凑多个模板的内容 |

**总分 ≥ 80 → 通过；< 80 → 退回重写**

### 5.2 AI模板词黑名单
```
禁用：
"不仅是...更是..." "在这个...的时代" "随着...的发展"
"他知道，从今以后..." "这一切，都源于..." "不得不说"
"令人...的是" "毫无疑问" "显而易见" "众所周知"
"心中涌起一股..." "眼中闪过一丝..." "嘴角微微上扬"
"内心深处" "灵魂深处" "命运的齿轮" "历史的车轮"

限制（每章≤2次）：
"宛如" "仿佛" "犹如"
"了"字句（每段≤1个）
"地"字状语（每500字≤3个）
```

### 5.3 去AI化6步粗筛
```
第1步：删模板词和套话
第2步：改情绪描写（抽象→具体行为/五感）
第3步：打散段落（长段→短段+对话+动作）
第4步：简化对话标签（删"他说道"类，改用动作衔接）
第5步：精简景物（删无效描写，保留功能性场景）
第6步：校验主线（改动后情节逻辑是否连贯）
```

### 5.4 情绪改写速查
| AI味原文 | 人话改写 |
|---------|---------|
| "他感到一阵无法言喻的愤怒涌上心头" | "他攥紧了拳头，指节发白" |
| "她的眼中闪过一丝复杂的情绪" | "她把茶杯放了又拿起来，拿了又放下" |
| "不得不承认，这确实令人震惊" | "操。他盯着屏幕，后背发凉" |
| "在这个弱肉强食的世界里" | "这地方不讲道理。有拳头就是爹" |
| "他知道，从今以后，一切都将不同了" | "他点了根烟。火星在黑暗里亮了又灭" |

## 六、番茄数据指标全量

### 6.1 核心指标达标线
| 指标 | 计算公式 | 达标线 | 不达标后果 |
|------|---------|--------|-----------|
| 书架比 | 加书架人数 ÷ 阅读人数 | ≥35% | 验证淘汰，不给放大推荐 |
| 追更比 | 追更人数 ÷ 阅读人数 | ≥35% | 不给放大推荐 |
| 第1章完读率 | 读完第1章 ÷ 点开第1章 | ≥60% | <60%说明开篇有严重问题 |
| 第3章完读率 | 读完第3章 ÷ 读第1章 | ≥45% | <45%说明黄金三章不合格 |
| 第10章完读率 | 读完第10章 ÷ 读第1章 | ≥25% | 检验长期留存能力 |

### 6.2 流量漏斗诊断表
```
展示量 → 点击率 → 第1章完读率 → 第3章完读率 → 追更比
```

| 流失位置 | 根因 | 优先检查 |
|---------|------|---------|
| 展示高但点击低 | 书名不吸引人 | 是否用了热词+身份+冲突+爽点公式 |
| 点击高但第1章完读低 | 开篇300字没冲突 | 开篇是否有景物/背景/心理描写 |
| 第1→3章完读断崖 | 金手指亮太晚/打脸没兑现 | 第2章是否700字内亮金手指 |
| 第5→10章持续下跌 | 节奏拖沓/憋屈太久 | 爽点间隔是否超过3章 |
| 书架高但追更低 | 章末无钩子 | 每章结尾是否有"下一章更爽"的信号 |
| 追更稳定但涨不动 | 缺少拉新元素 | 缺少可被短视频传播的名场面 |

| 评估维度 | 权重 | 高分标准 | 常见失分原因 |

## 八、日更节奏规范

| 规则 | 标准 | 超标后果 |
|------|------|---------|
| 开头300字必须出冲突 | 不允许有景物/背景/心理描写 | 读者划走 |
| 每章至少1次爽点 | 小爽=打脸/震惊/获得 | 完读率下降 |
| 每3章至少1次中爽 | 中爽=碾压/身份曝光/能力突破 | 追更比下降 |
| 憋屈不超2章 | 连续2章无爽点必翻车 | 大批弃书 |
| 每章结尾必须有钩子 | 信息钩/情绪钩/悬念钩轮换 | 追更比不够 |
| 日更6000字 | 约3-4章，每章1500-2000字 | 首秀淘汰 |
| 对话占比≥40% | 对话推动剧情，少用旁白 | 阅读疲劳 |
| 首秀期禁止修改 | 21天内不得修改任何已发布内容 | 推荐中断 |
| 验证期禁止断更 | 断更一天=验证中断 | 数据清零 |

## 十、平台AI检测机制（2026最新）

### 10.1 检测不是查重，是查"骨架"
平台不是简单比对文字重复度，而是从200+维度追溯"叙事指纹"和"故事骨架"是否由AI生成。

| 检测维度 | 原理 | AI文本特征 | 人类文本特征 |
|---------|------|-----------|------------|
| 困惑度(Perplexity) | 文本的"意外程度" | 总选最合理的下一个词→困惑度偏低 | 有意想不到的措辞/比喻→困惑度高 |
| 突发性(Burstiness) | 句子长度的变化幅度 | 句子长度均匀，像流水线码砖 | 三字句到整段话，变化剧烈 |
| 词汇分布 | 序列词/总结词/转折词密度 | 整洁均匀分布 | 混乱不均匀分布 |
| 句式结构 | 固定句式复用频率 | 高频复用 | 自然变化 |
| 叙事指纹 | 故事骨架是否为AI模式 | AI的"起承转合"模式固定 | 结构不规整，有个人风格 |
| 行为特征 | 提交节奏/修改痕迹 | 批量提交，修改少 | 不规则提交，大量修改 |

番茄2026年检测准确率已达95%以上，另有人工复审和读者举报两道防线。

| 平台 | AI辅助大纲 | AI辅助人设 | AI生成正文 | 处罚力度 |
|------|-----------|-----------|-----------|---------|

核心底线：**大纲可以用AI，正文不能让AI代笔。** 番茄要求AI辅助内容至少30%人工加工，起点要求核心剧情人工占比超过50%。

### 10.3 过审3层过滤法
```
第一层：提示词设计（预防）
  - 给足约束：性格/情绪/伏笔/禁用词/字数/风格
  - 禁止脏话、敏感隐喻、政治影射
  - 要求AI"完成后列出可能触发审核的词汇"

第二层：AI输出后自检（过滤）
  - 扫描：政治/宗教/暴力/色情/迷信/融梗6类红线
  - 逐章过"困惑度+Burstiness"主观判断
  - 句易网（免费）+ 秘塔写作猫（语义审核）

第三层：改写兜底（保险）
  - "情节转化为情绪"：不写行为写感受
  - "职业动作代替情绪"：不写愤怒写行动
  - "抽象化敏感场景"：不写自杀写天台边缘
```

### 10.4 叙事指纹反检测策略
| 策略 | 操作 | 目的 |
|------|------|------|
| 段落打散 | AI生成后手工打乱段落长度分布 | 提高Burstiness |
| 加脏句 | 每章加2-3句极其口语化的表达 | 提高困惑度 |
| 噪声词 | 添加行业黑话、方言、生僻词 | 破坏词汇分布均匀性 |
| 结构扰动 | 不按AI的"起承转合"模板走 | 破坏叙事指纹 |
| 修改痕迹 | 分批保存、多次修改 | 模拟人类创作行为 |

### 11.1 案例A：日更3万字，月入2.5万

```
Step 3: Claude生成正文 → 对话≥40%，每500字一个冲突点，前300字有钩子
Step 4: 人工精修 → 改三样：对话自然度、情绪铺垫、逻辑连贯
Step 5: 多书并行 → 番茄+知乎盐选双平台，不同题材不同策略
```
