# 番茄爆款网文句法搭配手册 v2.0

> 基于番茄/起点爆款拆解 × 多源数据交叉验证 × 平台检测机制逆向
> 核心问题：什么样的句子结构和用词能让番茄读者上头、让算法推流、让AI检测查不出来

---

## 一、核心结论：句法四大铁律

### 铁律1：抽象情绪词是毒药，具体形容词有限使用

爆款网文和普通写作最大的分水岭是**动词密度**和**情绪的具象化程度**。

| 对比 | 普通写法 | 爆款写法 |
|:---|:---|:---|
| 情绪描写 | 「他很悲伤」 | 「他攥着那张纸，手指关节发白，纸边被捏出了褶皱」 |
| 动作描写 | 「他快速地跑过去」 | 「他撞开人群，膝盖磕在台阶上，爬起来继续跑」 |
| 对话归属 | 「青龙的声音低，」 | 「青龙压低声音说，」 |
| 外貌描写 | 「她长得很漂亮，五官精致」 | 「她走进来的时候，所有人的目光都停了一下」 |

**动词密度三级标准**（基于5本真实爆款实测）：

| 级别 | 标准 | 适用场景 | 代表作品 |
|------|:--:|------|------|
| 入门及格线 | 8-12个/百字 | 能签约，竞争力一般 | 大部分签约作品 |
| 爆款常见线 | 12-18个/百字 | 节奏感明显，留存好 | 《开局我是申公豹》(12.7) |
| 极致风格线 | 20-27个/百字 | 冷白描/战术报告体，需配合极短句 | 《绝世唐门同人》(23.4)、《都重生了我还不能模仿了?》(27.0) |

> ⚠️ 极致风格（27+密度）常伴随极短平均句长（9-14字），不适合对话密集型题材。不可盲目堆动词。

**动词驱动原理**：
- 读者读到动词时，大脑会**模拟动作**（镜像神经元激活），产生代入感
- 读者读到抽象形容词时（"很生气""非常悲伤"），大脑只做**概念匹配**，不产生画面
- 具体形容词（"冰冷的石面""发白的指节"）是有效的，因为它承载了感官信息

**形容词使用规则**：只用于两类场景。
1. 关键意象——全篇1-2处：「祭坛的石面是冷的，冷得不像是石头，像是埋了一千年的铁」
2. 对话中的口语化表达——「你这人怎么这么慢！」

---

### 铁律2：主语不能永远是「他/她」

**常见错误**：连续3句以上用同一主语开头。

```
❌ 错误范例：
他走到门口。他推开门。他看到了她。他愣住了。
他张了张嘴。他想说什么。他什么也没说出来。

✅ 正确范例：
他走到门口，推开门。
看到她的一瞬，脚步停住了。
张了张嘴，一个字也没说出来。
```

**主语变换策略**：

| 方式 | 示例 | 效果 | 叙述距离 |
|:---|:---|:---|:---|
| 省略主语（承前省） | 「他走到门口，推开门。看到她的一瞬，脚步停住了。」 | 节奏加快，动作连贯 | D1 |
| 换主语为动作结果 | 「拳头砸在墙上。墙皮簌簌往下掉。」 | 视角从人物转移到世界 | D1-D2 |
| 换主语为感官 | 「鼻腔里全是血腥味。胃里翻了一下。」 | 最强代入感，拉近叙述距离 | D0 |
| 换主语为对方 | 「沈鹿鸣看着他。他没有避开她的目光。」 | 制造对峙感 | D1-D2 |

**硬指标**：连续3个段落不要用同一主语开头。

---

### 铁律3：句子结构必须「长短交替」

**句式单调 = 阅读疲劳**。

| 模式 | 效果 | 使用场景 |
|:---|:---|:---|
| 长句（25-40字） | 舒缓、信息量大 | 描写、叙事、铺垫 |
| 中句（10-25字） | 正常节奏 | 对话、动作 |
| 短句（3-10字） | 急促、有力 | 战斗、高潮、情绪爆发点 |
| 单字句 | 极强冲击力 | 「走。」（非对话场景慎用，手机屏上单字占一行阅读体验差） |

**句式分布参考（分场景）**：

| 场景类型 | 短句(≤10字) | 中句(11-20字) | 长句(>20字) |
|---------|:--:|:--:|:--:|
| 战斗/动作高潮 | 70-80% | 15-25% | <5% |
| 日常叙事/铺垫 | 15-25% | 50-60% | 20-30% |
| 情绪高潮/虐点 | 50-60% | 30-40% | <10% |
| 对话场景 | 60-80% | 20-30% | <5% |

---

### 铁律4：对话占比≥40%，标签省略率≥60%

番茄读者用手机看。纯叙事段落超过200字不换行，眼睛就跑了。只有对话能让屏幕持续变化。

| 维度 | 量化标准 | 超过/不足后果 |
|------|---------|-------------|
| 对话占比 | 40-60% | 低于40%=叙事拖沓，高于60%=信息量不足 |
| 对话标签省略率 | ≥60% | "说道/问道"每句都出现=AI味信号 |
| 每屏视觉变化 | ≤200字内至少1次 | 超过200字全是同样密度的文字=读者划走 |

```
❌ 每句对话都带标签（AI味）：
"你来了。"他说。
"嗯。"她回答道。
"路上堵车了。"他解释道。

✅ 动作替代标签（人类味）：
"你来了。"
门推开，她站在门口，头发上还挂着雨珠。"路上堵了四十分钟。"
他把毛巾递过去。"先去换衣服。"
```

## 二、主谓宾搭配：爆款 vs 普通对比

### 2.1 对话归属——最常出问题的位置

**问题等级：🔴 致命**

| 写法 | 例子 | 评价 |
|:---|:---|:---|
| ❌ 形容词作谓语 | 「青龙的声音低，」 | 网文节奏不佳，缺动感（注：语法本身正确，但静态状态无法激活读者镜像神经元） |
| ❌ 形容词作谓语 | 「他的语气冷，」 | 同上 |
| ✅ 动补结构 | 「青龙压低声音说，」 | 动词+补语，有画面触发 |
| ✅ 动补结构 | 「他的声音沉下来，」 | 动词+补语，有画面触发 |
| ✅ 动词+情态 | 「他放缓了语气，」 | 动词+补语，有画面触发 |
| ✅ 直接动作替代 | 「他沉默了片刻，」 | 用动作替代声音描述 |
| ✅ 直接动作替代 | 「他清了清嗓子，」 | 用动作替代声音描述 |

**规律**：网文对话归属公式是 **「主语 + 动词 + 补语/状语 + 说/道」**，而不是「主语 + 名词 + 形容词」。

**常用归属动词库**：
```
压低声音、放缓语气、沉声、冷声、哑着嗓子、
提高音量、带着笑、咬着牙、从牙缝里挤出来、
语气平淡、声音发紧、话里带着刺
```

**对话六不写原则**：
1. 不让「XX说」「XX道」连续出现超过3次——3次后必须用动作替代或省略
2. 不让两个角色连续说同长度的话——A说15字，B回3字，才有对话感
3. 不让对话变成信息说明书——角色之间不会互相告诉已经知道的事
4. 不让每句对话都有归属——你一句我一句时省略标签，读者能分辨
5. 不让对话结束后用旁白复述——「他说他很生气」是多余的
6. 不让所有角色说话一个腔调——给每个角色一个口头禅/习惯用语/称呼方式

---

### 2.2 情绪描写——用动词替代形容词

**问题等级：🔴 致命**

| 表达方式 | 例子 | 效果 |
|:---|:---|:---|
| ❌ 抽象情绪词 | 「他感到很愤怒」 | 读者无感 |
| ❌ 抽象情绪词 | 「她觉得很委屈」 | 读者无感 |
| ❌ 抽象情绪词 | 「他心里一阵恐惧」 | 读者无感 |
| ✅ 身体反应 | 「他的手指掐进掌心，指甲发白」 | 读者能感受 |
| ✅ 身体反应 | 「她咬着下唇，嘴唇在发抖」 | 读者能感受 |
| ✅ 动作展示 | 「他一拳砸在墙上，骨节裂开」 | 读者能感受 |
| ✅ 对话展示 | 「她声音很轻：'你再说一遍。'」 | 读者能感受 |

**情绪-身体映射表**：

| 情绪 | 不要写 | 要写 |
|:---|:---|:---|
| 愤怒 | 「他非常生气」 | 「他攥紧拳头，指节咔咔响」 |
| 恐惧 | 「她很害怕」 | 「她后背贴着墙，冷汗顺着脊椎往下流」 |
| 紧张 | 「他紧张得不行」 | 「他喉结上下滚了一下，手心全是汗」 |
| 悲伤 | 「他很伤心」 | 「他低着头，肩膀在抖，没出声」 |
| 惊讶 | 「他很震惊」 | 「他张了张嘴，一个字也没说出来」 |
| 尴尬 | 「她很尴尬」 | 「她把脸别过去，耳朵尖烧得通红」 |
| 期待 | 「他充满期待」 | 「他每隔几秒就看一眼手机」 |

---

### 2.3 环境描写——不要在开篇堆砌

**问题等级：🟡 重要**

| 写法 | 例子 | 评价 |
|:---|:---|:---|
| ❌ 纯环境开场 | 「夜晚的月光洒在祭坛上，风轻轻吹过……」 | 读者在300字内离开 |
| ❌ 形容词堆砌 | 「古老的、斑驳的、布满青苔的石墙」 | 信息量低，节奏慢 |
| ✅ 环境+人物动作 | 「夜岚跪在祭坛上，额头贴着冰冷的石面。月光从穹顶裂缝漏下来，照着她的后背。」 | 环境通过人物感知呈现 |
| ✅ 环境+故事信息 | 「铁门轰然关上，锁扣咔嗒落下。门外是暗月森林，门内是她的前半生。」 | 环境承载叙事功能 |

**环境描写公式**：
```
人物的动作/感知 + 环境的一个关键细节 + 这个细节对人物的影响
```

## 三、动词运用的四个层级

### 层级1：一个动词 = 一个动作

**最基本的要求**。每个动词对应一个具体的物理动作。

| ❌ 模糊动词 | ✅ 具体动词 |
|:---|:---|
| 他弄了一下 | 他拧了一下 / 他掰了一下 / 他扯了一下 |
| 她处理了伤口 | 她撕开纱布，碘伏倒上去，咬着牙缠了两圈 |
| 他收拾了东西 | 他把手机揣进兜里，拉上背包拉链，踢开椅子站起来 |

### 层级2：动词链 = 连续动作

**爆款写法**。用连续动词串起一个场景。

```
他撞开人群，膝盖磕在台阶上，爬起来继续跑。
```

三个动词（撞开→磕→爬起来→跑）比任何形容词都有效。

### 层级3：动词 + 结果 = 力量感

**动作 + 该动作造成的结果**。

```
他一拳砸在桌上。桌面炸裂，木屑飞溅。
```

「砸」是动作，「炸裂木屑飞溅」是结果。读者同时看到动作和后果。

### 层级4：动词替代情绪标签

**最高级用法**。用动作替代「他感到/他觉得/他明白」。

```
❌ 「他意识到自己错了。」
✅ 「他的手垂下来，什么也没说。过了很久，才哑着嗓子开口：『是我的错。』」
```

## 四、形容词的正确用法

### 4.1 什么时候可以用形容词

1. **关键意象**（全篇1-2处）
2. **对话中的口语化表达**
3. **承载感官信息的限定性形容词**（"冰冷的石面""发白的指节""锈蚀的门把手"——这些告诉读者温度/颜色/材质，而不是替读者感受）

### 4.2 什么时候不能用形容词

| 场景 | 禁止/限制的原因 |
|:---|:---|
| 情绪描写 | 抽象情绪词让读者出戏 |
| 对话归属 | 「声音低/轻/沉」缺动感 |
| 开篇环境 | 读者需要事件，不是风景 |
| 外貌描写 | 读者需要想象空间，不是清单 |
| 战斗描写 | 读者需要动词，不是修饰 |

### 4.3 形容词的替代方案

| 想表达的 | 不要写 | 要写 |
|:---|:---|:---|
| 她很漂亮 | 「她长得很漂亮」 | 「她走进来的时候，酒馆里安静了三秒」 |
| 他很强大 | 「他的实力很强」 | 「他一掌拍下去，地面裂开一道三丈长的裂缝」 |
| 房间很豪华 | 「房间装修豪华」 | 「水晶吊灯往下坠了三层，地毯厚得能陷进去半只脚」 |
| 这把刀很锋利 | 「刀很锋利」 | 「刀锋划过空气，连声音都没留下」 |

## 五、通感写作：让读者"自己感受"（番茄头部标配）

通感是把一种感官映射到另一种感官。它不仅告诉读者"看到什么"，还让读者"自己产生情绪"。

**通感 vs 五感的区别**：
- 五感让读者「看到」世界——这是描写的基础层
- 通感让读者「自己感受到」情绪——这是让读者上头的触发器

**通感三公式**：

| 公式 | 原理 | 示例 |
|------|------|------|
| 视觉→听觉 | 把画面"听"出来 | 「夕阳落下去的时候，橘红色的光撞在山脊上——他好像听到了光碎掉的声音」 |
| 触觉→视觉 | 把感觉"看"出来 | 「会议室里的安静是有重量的。他看见每个人的沉默都凝成了半透明的灰色，从天花板上压下来」 |
| 味觉→情绪 | 让情绪有味道 | 「奖杯的金属味钻进鼻腔——闻起来像过去三年所有的委屈，一起被烧成了灰」 |

**使用规则**：每3000字1-2处为佳，超过3处会腻。通感是盐，撒对了整道菜活了，撒多了齁死。

## 六、句法节奏控制

### 6.1 战斗场景的句法

```
❌ 错误：全是长句
「他迅速地从腰间拔出那把锋利的匕首，以一个极其刁钻的角度刺向对方的咽喉，对方反应也很快，侧身躲开了这一击，然后反手一肘砸向他的后背。」

✅ 正确：短句为主
「刀出鞘。没有声音。
刃尖直取咽喉。
他侧身。刀锋贴着耳朵划过。
反手一肘砸下去。
肋骨断了。闷响。
对方后退三步，跪在地上。」
```

**战斗场景句式规则**：
- 70-80%为短句（≤10字）
- 每个动作独立成句
- 动作结果紧接着动作
- 不出现「然后」「接着」「随即」

### 6.2 情绪场景的句法

```
❌ 错误：名词堆砌
「她的心里充满了悲伤和绝望，眼泪像断了线的珠子一样往下掉，她不知道自己该怎么办才好。」

✅ 正确：身体反应+短句
「她蹲下来。
抱着膝盖。
眼泪掉在地上，洇开一小片深色。
她没出声。
哭不出声的那种。」
```

**情绪场景句式规则**：
- 50-60%短句拉近距离（D0-D1）
- 每个短句展示一个身体细节
- 不在叙事中替角色总结情绪
- 留白：让读者自己感受

### 6.3 对话场景的句法

**对话归属的位置**：

| 位置 | 效果 | 示例 |
|:---|:---|:---|
| 对话前 | 最清晰，适合新说话人出场 | 「顾九说：『先喝汤。』」 |
| 对话中 | 节奏变化，适合长对话 | 「『你退婚那天，』她说，『我跪在祭坛上求你。』」 |
| 对话后 | 加速节奏，适合短回应 | 「『滚。』她说」 |
| 省略归属 | 连续对话时，读者能分辨 | 「『去哪？』『散步。』『散步？』『走就行。』」 |

## 七、叙述距离：句法的底层逻辑

**问题**：为什么短句+感官主语比长句+他/她主语更有代入感？

答案在叙述距离。John Gardner在《The Art of Fiction》中定义了五级叙述距离：

| 级别 | 特征 | 读者体验 | 网文适用场景 | 典型句法 |
|------|------|---------|------------|---------|
| **D0** | 完全融入角色感知，叙述者消失 | "我就是这个人" | 情绪高潮、战斗、复仇打脸 | 短句+感官主语 |
| **D1** | 自由间接引语，角色声音穿透叙述 | "我听到他在想什么" | 虐点、爽点、关键抉择 | 中短句+省略主语 |
| **D2** | 近距离第三人称 | "我紧挨着这个人" | 日常叙事、过渡段落 | 中长句+他/她主语 |
| **D3** | 中距离概括 | "我看到了他的经历" | 时间跳跃、背景压缩 | 长句+概括性语言 |
| **D4** | 远距离客观记录 | "我在看资料" | 历史背景、世界观交代 | 超长句+全知叙述 |

**句法与叙述距离的对应**：
- 短句（≤10字）+ 感官主语（"鼻腔里全是血腥味"）= D0 → 最强代入感
- 中句 + 省略主语 = D1 → 自然代入
- 长句 + 他/她主语 = D2-D3 → 叙述型
- 超长句 + 概括性语言 = D4 → 最弱代入感

**使用规则**：一章内应在 D0-D3 之间流动，不要锁死一个距离。开篇300字用D0（直接砸进冲突），过渡段用D2（叙事），高潮段回到D0。

## 八、手机阅读视觉节奏（番茄特有）

**关键事实**：番茄90%+流量来自手机。一屏约150-200字。排版密度直接影响完读率。

| 规则 | 标准 | 原因 |
|------|------|------|
| 段落长度 | ≤3行（约150字） | 超过3行的段落，手机读者跳过率>70% |
| 对话单独成行 | 每句对话独占一行 | 混在段落里的对话会被眼睛跳过 |
| 每屏视觉变化 | ≤200字内至少1次 | 空行/对话/短句/动作——让眼睛有停留点 |
| 章节开头 | 首段≤2行 | 第一屏决定读者是否继续划 |
| 战斗/高潮段落 | 每行≤15字 | 密集短句制造呼吸急促的阅读体验 |

```
❌ 手机排版灾难：
林辰穿过走廊推开会议室的门里面坐满了人所有人的目光都落在他身上他走到空位坐下清了清嗓子说今天我们要讨论的是下个季度的预算问题在座的都是各部门的负责人我希望大家能够坦诚地交流把各自的需求和困难都说出来我们一起想办法解决。

✅ 手机阅读舒适：
林辰穿过走廊。推开会议室的门。
里面坐满了人。
所有目光落在他身上。
他走到空位，坐下，清了清嗓子。
"下个季度的预算。"
他扫了一圈。
"各部门把需求摆出来。我们一起想办法。"
```

## 九、口语化/网感指标

网感不是用网络热词，而是"用读者最舒服的方式讲故事"——具体到句法就是口语化程度。

| 维度 | 量化标准 | 说明 |
|------|---------|------|
| 语气词密度 | 每3000字3-5个 | "嘤""嘶""靠""行吧""啧""嗯""操"——让角色说话有声音特征 |
| 碎片化小动作 | 每500字1个 | 搓指尖、走神、视线飘开、下意识抿嘴——对抗AI检测的关键 |
| 句式不完美原则 | 每章至少2处 | 允许轻微粗糙感：半截话、改口、犹豫——AI不会写这种 |
| 方言/口头禅 | 每个主要角色至少1个 | 如"行吧""啧""成"——降低对话模板被识别概率 |

**句式不完美示例**：
```
❌ AI味（逻辑太完美）：
"我仔细想了想，觉得你说得对。但是我还是有一点顾虑，就是关于资金的来源问题——你确定那个投资人可靠吗？"

✅ 人类味（有改口和犹豫）：
"行吧……你说得对。"
他顿了一下。
"不对，等等——那个投资人的底，你查过没有？"
```

## 十、AI腔检测与规避（2026最新）

### 10.1 平台检测机制

番茄2026年检测系统从200+维度追溯"叙事指纹"，核心在四层：

| 检测层 | 原理 | 反检测策略 |
|--------|------|-----------|
| 困惑度(Perplexity) | AI总选最合理的下一个词→困惑度偏低 | 每章加2-3句口语化/意外表达 |
| 突发性(Burstiness) | AI句子长度均匀如流水线 | 不得连续3句同长度 |
| 词汇分布 | AI的序列词/转折词密度均匀 | 破坏整洁分布 |
| 叙事指纹 | AI的"起承转合"模式固定 | 打破标准叙事结构 |

检测准确率已达95%+，另有读者举报和人工复审。

### 10.2 句法级AI模式（红线）

| 模式 | 例子 | 警戒线 | 说明 |
|:---|:---|:---|:---|
| 并非X，是Y | 「那个眼神并非我赢了，是你安全了」 | ≤1次/章 | 禁止出现在情绪高潮场景 |
| 不是X，是Y | 「不是水，是血」 | ≤2次/章 | |
| 深吸一口气 | 「她深吸了一口气，推开门」 | ≤1次/章 | 如有替代方案优先替换为当下动作 |
| 闭上眼睛 | 「他闭上眼睛，感受着」 | ≤1次/章 | 优先用"垂下眼/移开视线" |
| 仿佛/似乎/宛如 | 「月光仿佛银色的瀑布」 | ≤2次/3000字 | 优先直接白描 |
| ……一样 | 「像刀子一样锋利」 | ≤1次/3000字 | |
| 然后+X | 「然后他走到门口，然后推开门」 | ≤1次/章 | 战斗场景禁用 |
| 他/她X了，Y了 | 「他站了起来，走到了门口」 | ≤3次/段 | |

### 10.3 AI万能套词黑名单

以下词汇被AI过度使用，人类作者每章极少出现超过1个。如果一章出现3个以上，AI检测概率显著上升：

```
喉结滚动、眼底寒光、周身气场、心中五味杂陈、
一股寒意席卷全身、气氛瞬间凝滞、瞳孔微缩、
心头一震、嘴角勾起一抹、头皮发紧、眼皮一跳、
心口一沉、胃里翻涌
```

### 10.4 标准化副词黑名单

以下副词本身正确，但AI过度使用（每章出现5+次即为AI味信号）。人类作者使用频率约每3000字1-2次：

```
缓缓、微微、骤然、蓦地、陡然、霎时
```

### 10.5 人类写作 vs AI写作速查

| 特征 | 人类 | AI |
|:---|:---|:---|
| 句子长度分布 | 不均匀，有长有短 | 均匀，偏中等 |
| 主语选择 | 多变，省略/换主语频繁 | 固定，他/她为主 |
| 动词密度 | 高，每百字12-27个 | 低，每百字4-6个 |
| 错别字/口语化 | 有，自然 | 无，过于规整 |
| 句式结构 | 灵活，口语化 | 严谨，书面化 |
| 段落长度 | 变化大 | 均匀 |
| 对话归属 | 多样化，60%+省略 | 模板化，说/道为主 |
| 结尾方式 | 动作/对话收尾 | 总结/升华/感慨收尾 |

## 十一、实战对照：你写的 vs 爆款写的

### 场景1：角色低声说话
| 版本 | 写法 |
|:---|:---|
| ❌ 你的 | 「青龙的声音低，『数了也没用。』」 |
| ✅ 改后 | 「青龙压低声音说，『数了也没用。』」 |
| 🏆 爆款 | 「青龙没抬头，声音压得很低，像是怕被什么人听见——『数了也没用。』」 |

### 场景2：角色情绪变化
| 版本 | 写法 |
|:---|:---|
| ❌ 你的 | 「她感到很害怕」 |
| ✅ 改后 | 「她后背贴着墙，手心全是汗」 |
| 🏆 爆款 | 「她退了一步，后背撞到墙。没有再退。心跳声在耳朵里轰轰响，但她没有移开视线。」 |

### 场景3：动作描写
| 版本 | 写法 |
|:---|:---|
| ❌ 你的 | 「他迅速地拔出匕首，刺向对方」 |
| ✅ 改后 | 「刀出鞘。刃尖直取咽喉。」 |
| 🏆 爆款 | 「刀光一闪。他低头看胸口——血从指缝里渗出来。什么时候出的刀？没看清。」 |

### 场景4：环境描写
| 版本 | 写法 |
|:---|:---|
| ❌ 你的 | 「这是一个古老的祭坛，月光从上面照下来」 |
| ✅ 改后 | 「夜岚跪在祭坛上，额头贴着冰冷的石面。月光从穹顶的裂缝漏下来。」 |
| 🏆 爆款 | 「她跪着。额头贴着石头，凉意从皮肤渗进骨头里。月光从头顶的裂缝漏下来，照在她面前——在地面上投下一道栅栏的影子，像牢笼。」 |

## 十二、完整的自检清单

### 句法级
```
□ 是否有「XX的声音+单字形容词」作谓语？（有→改动补结构）
□ 对话标签省略率是否≥60%？（"说/道"连续出现不超过3次）
□ 对话占比是否≥40%？
□ 是否有「并非/不是X，是Y」句式？（≤1次/章）
□ 是否有「深吸一口气/闭上眼睛」模板？（≤1次/章，有替代则替换）
□ 是否有「然后+X」过渡词？（≤1次/章，战斗场景禁用）
□ 是否有「他/她X了，Y了」的固化句式？（≤3次/段）
□ 是否有「仿佛/似乎/宛如/像…一样」比喻？（≤2次/3000字）
□ 是否有AI万能套词？（喉结滚动/眼底寒光/周身气场/瞳孔微缩/心头一震等）
□ 是否有标准化副词过量？（缓缓/微微/骤然/蓦地/陡然/霎时，≤2次/3000字）
□ 连续3句主语是否不同？
□ 连续3句长度是否不同？
```

### 情绪级
```
□ 是否有「他感到/他觉得/他知道/他明白」等抽象情绪词？
□ 情绪是否用了身体反应（手抖/咬牙/掐掌心/喉咙发紧）？
□ 对话归属是否有动词？（压低声音说/沉声道/哑着嗓子）
□ 战斗场景是否70-80%为短句（≤10字）？
□ 情绪场景是否用身体细节+短句拉近到D0？
```

### 动词级
```
□ 每百字动词密度是否达标？（入门≥8，爆款≥12）
□ 动词是否具体？（不是「弄/搞/做了」，是「拧/掰/扯/撕」）
□ 关键动作是否有「动作+结果」？
□ 环境描写是否通过人物感知呈现？
```

### 手机阅读级
```
□ 是否有超过3行（约150字）的段落？（超过→拆）
□ 对话是否单独成行？
□ 每≤200字是否有视觉变化（空行/对话/短句）？
□ 章节开头是否≤2行？
```

### 网感/AI对抗级
```
□ 每3000字是否有3-5个语气词（嘤/嘶/靠/啧）？
□ 每500字是否有1个碎片化小动作？
□ 每章是否有至少2处"句式不完美"（半截话/改口/犹豫）？
□ 结尾是否用动作/对话收尾？（禁止总结/升华/感慨）
□ 是否每3000字用了1-2处通感？
□ 是否做到了句式"不完美原则"——允许轻微粗糙和自然留白？
```
