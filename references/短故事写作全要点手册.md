## 第一章 开篇：黄金三章（S1）

**权重**: 25%（整篇检测中权重最高的模块）

### 1.1 前300字钩子

前300字必须让读者产生「必须往下看」的冲动。检测以下4类钩子信号，**至少命中2个**：

| 钩子类型 | 关键词 | 示例 |
|:---|:---|:---|
| **事件钩子** | 突然/没想到/竟然/死/杀/跪/崩溃/完了 | 「婚礼上，新郎的剑刺穿了她的胸口。」 |
| **情感钩子（重生复仇类）** | 上一世/前世/含恨/含冤/背叛/陷害/不甘心 | 「上一世她死在这杯毒酒下，这一世……」 |
| **穿书/系统类钩子** | 穿书/穿越/系统/弹幕/直播间/攻略/离婚协议 | 「穿成虐文女主，开局就要被献祭。」 |
| **对比类钩子** | 上一世…这一世/曾经…如今/我以为…却 | 「上一世她跪着求他，这一世她站着笑。」 |

**硬指标**：前300字内至少出现2个钩子信号。

**常见问题**：
- ❌ 只有环境描写没有事件。「月光洒在祭坛上，风轻轻吹过……」→ 读者没被拽住
- ❌ 钩子信号单一。只靠一个「跪」字撑300字 → 不够
- ✅ 冲突+情感双重钩子。「退婚书砸在脸上。她跪着，指甲嵌进掌心。上一世，她也是这样跪着死的。」

### 1.2 开篇冲突

前300字内必须发生冲突。冲突信号包括：

| 冲突类型 | 检测关键词 | 最低数量 |
|:---|:---|:---|
| 物理冲突 | 打/杀/刺/毒/跪/撕/砸/摔 | ≥3处 |
| 情感冲突 | 背叛/陷害/离婚/分手/羞辱/逼/求 | ≥3处 |
| 身份冲突 | 退婚/逐出/废除/贬为/剥夺 | ≥2处 |

**硬指标**：前300字冲突信号 ≥ 3处。

### 1.3 第一章尾钩子

第一章结尾必须有强钩子，让读者必须翻到第二章。检测的5种模式：

| 钩子类型 | 关键词 | 示例 |
|:---|:---|:---|
| 断章取义型 | 刚要/正要/话没说完/突然发现/一脚踹开 | 「话没说完，门被一脚踹开——」 |
| 危机降临型 | 瞳孔收缩/杀意/完了/出事了/冲进来 | 「他回头一看，刀刃已经到了面前。」 |
| 情绪反转型 | 没想到/竟然/原来/背叛 | 「她笑着接过信，看完之后脸色惨白。」 |
| 伏笔植入型 | 黑影/脚步声/突然想起/角落/发烫/闪烁 | 「角落里站着一个本不该出现在这里的人。」 |
| 情感收束型（金句） | 不过是/这辈子/我不会再/冷笑/宣言式对话 | 「这一世，我不做棋子。」 |

**硬指标**：第一章尾至少命中2个模式。单独1个偏弱。

**关键认知**：第一章不能是「预告片」，必须是「第一集」。第一章结束时要交付一个完整的爽点（打脸/反转/信息揭秘），不能只做铺垫。

**第1章结构铁律**：
```
❌ 错误模式（只设局不交付）：
   退婚 → 被逐 → 坠崖（END）→ 读者：然后呢？！

✅ 正确模式（交付完整爽点）：
   退婚当面对峙 → 被逐 → 坠崖 → 觉醒 → 展现力量 → 章尾埋更大悬念
```

## 第二章 章节结构（S2）

**权重**: 15%

### 2.1 字数控制

| 类型 | 推荐字数 | 上限 | 下限 |
|:---|:---:|:---:|:---:|
| 短故事（番茄） | 2000-3000字/章 | 3000字 | 1500字 |
| 长篇单章 | 2500-3000字 | 3500字 | 2000字 |

**硬指标**：
- 低于1500字 → 严重过短，必须扩充
- 1500-2000字 → 偏短，建议补内容
- 2000-3000字 → 黄金区间 ✅
- 超过3000字 → 略长，考虑拆分或精简
- 超过3500字 → 必须拆分

### 2.2 句子长度

**硬指标**：每章中超过25字的句子占比不宜过高。

- 短句（≤15字）：占60-70%，适合对话和动作
- 中句（16-25字）：占20-30%，适合叙述
- 长句（>25字）：≤10%，只用于特殊描写

### 2.3 对话占比

| 类型 | 推荐对话比 | 下限 |
|:---|:---:|:---:|
| 现代/都市文 | 40-60% | 30% |
| 古风/古言 | 35-55% | 25% |
| 战斗/动作章 | 25-40% | 20% |
| 叙事/过渡章 | 20-35% | 15% |

**⚠️ 这是短故事最重要的指标之一**。对话比过低的章节会让读者觉得沉闷、缺乏互动感。

**如何提高对话比**：
1. 把叙事段中的关键信息改为对话交付
2. 冲突场景必须用对话+动作推进，不要用叙述
3. 两个人物的交谈比一个人内心活动更容易拉住读者
4. 战斗场景也要穿插对话对呛

### 2.4 段落控制

| 标准 | 要求 |
|:---|:---|
| 每段字数 | ≤3行（手机阅读舒适区） |
| 段落节奏 | 叙事段≤5行，对话段1-2行 |
| 长段落处理 | 超过5行的段落必须拆 |

## 第三章 章末钩子（S3）

**权重**: 20%

### 3.1 钩子覆盖率

**硬指标**：所有章节的结尾必须有钩子。允许1-2章无钩子（如高潮后过渡章），但覆盖率 ≥ 85%。

### 3.2 钩子类型多样性

5种钩子类型必须交替使用，不能连续3章同一类型。

| 类型 | 适用场景 | 使用频率 |
|:---|:---|:---:|
| 断章取义型 | 任何章节 | 25% |
| 危机降临型 | 战斗/冲突章节 | 25% |
| 情绪反转型 | 剧情转折点 | 20% |
| 伏笔植入型 | 过渡/铺垫章节 | 15% |
| 情感收束型(金句) | 高潮后/独处场面 | 15% |

### 3.3 钩子强度判断

- **强钩子**（≥2个模式命中）：✅ 读者会想看下一章
- **弱钩子**（仅1个模式命中）：⚠️ 建议加强
- **无钩子**（0个模式命中）：🔴 必须补

### 3.4 无钩子章节的常见类型

| 章节类型 | 问题 | 解决方案 |
|:---|:---|:---|
| 情感收束章 | 结尾「她转身，走进黎明」 | 在收束后加一个事件触发 |
| 视角切换章 | 切换到配角视角，没做钩子 | 在配角视角最后切回主角悬念 |
| 过渡章 | 只是「去到某地/准备某事」 | 在到达之前制造一个障碍/意外 |

## 第四章 情绪节奏（S4）

**权重**: 25%（并列最高）

### 4.1 爽点间隔

**硬指标**：爽点间隔 ≤ 3章。超过3章没有爽点，读者会弃书。

爽点类型：
- **打脸型爽点**：主角碾压对手，让对方吃瘪
- **信息揭秘型爽点**：主角掌握别人不知道的信息
- **成长型爽点**：主角突破瓶颈/觉醒新能力
- **身份反转型爽点**：废柴→强者，卑微→尊贵

### 4.2 虐爽比例

**硬指标**：虐感内容占比 ≤ 30%。

- 虐（憋屈/挫折/压抑）：≤ 30%
- 爽（打脸/反杀/成长/高潮）：≥ 70%

**情绪曲线标准模式**：
```
憋屈(≤3章) → 小爽 → 升级憋屈 → 中爽 → 大高潮 → 余韵
            ↑________________________↓
```

### 4.3 憋屈节奏陷阱

**常见错误**：
1. ❌ 憋屈太短就释放 → 读者还没代入就爽了，没感觉
2. ❌ 憋屈视角在反派身上 → 读者不共情
3. ❌ 没有「至暗时刻」 → 全程爽没有低谷，高潮没有对比

**正确做法**：
- 憋屈至少持续1-2章让读者代入了再释放
- 憋屈必须在主角视角（让读者跟着难受）
- 故事要有至少1个「all is lost moment」

### 4.4 情绪走势

**硬指标**：后劲 > 前劲。整体情绪曲线必须上升。

```
❌ 错误：高潮在中间，后面越写越平
✅ 正确：逐级上升，最大的高潮在结尾前
```

## 第五章 人设逻辑（S5）

**权重**: 15%

### 5.1 反派降智检测

**硬指标**：反派不能为了剧情需要而突然变蠢。

| 降智表现 | 判定 | 处理 |
|:---|:---:|:---|
| 反派突然说出全部计划 | 🔴 必改 | 改为只露部分，留白 |
| 反派在优势时放弃优势 | 🔴 必改 | 给合理理由（轻敌/被干扰） |
| 反派信任不该信的人 | 🟡 视上下文 | 如果有铺垫（如被蒙蔽）可保留 |
| 反派忘了主角的信息差 | 🟡 视上下文 | 检查前文是否有铺垫 |

### 5.2 女主恋爱脑检测

**硬指标**：女主不能为了感情而放弃理智。

工具会扫描以下内容排除假性信号（对话中的内容不计入）：
- 女主是否在叙事中频繁为反派找理由
- 女主是否明知危险还主动送
- 女主是否忘记核心目标

### 5.3 情感转变依据

**硬指标**：情感转变必须有合理铺垫。

| 转变类型 | 最少需要的铺垫 | 示例 |
|:---|:---|:---|
| 恨→释然 | 至少1个让女主动摇的事件 | 对方舍命相救 |
| 防备→信任 | 至少2次验证 | 对方两次在关键时刻站她这边 |
| 冷漠→心动 | 至少3个细节积累 | 细微的照顾/眼神/动作 |

### 5.4 人物情绪铁律（冷静≠冷漠）

**这是最核心的人物塑造教训**：

| ❌ 错误写法（冷静=冷漠） | ✅ 正确写法（冷静=压着火） |
|:---|:---|
| 心里没有一丝波动 | 拳头攥紧、指甲掐进掌心 |
| 温和、客气、讲道理 | 冷笑、讽刺、偶尔爆粗口 |
| 一直很平静 | 独处时才让眼泪掉下来 |
| 和男主客气对话 | 互相试探有火药味 |

**每章情绪爆点密度**：

| 章节类型 | 至少需要 | 示例 |
|:---|:---|:---|
| 重生醒来 | 恨意翻涌+生理反应 | 心跳狂跳、手抖、摔东西 |
| 见到仇人 | 生理厌恶+眼神交锋 | 冷笑、眼神像刀子 |
| 被敌人打压 | 憋屈但不能认输 | 咬碎牙往肚子里咽 |
| 打脸成功 | 平静地看对方崩溃 | 比大笑更有力 |
| 独处/脆弱 | 才让情绪漏出来 | 无声流泪、捶墙 |

## 第六章 叙事质量（S7）

**权重**: 辅助参考（不计入总分，但影响编辑/读者观感）

### 6.1 AI句式：「不是X，而是Y」

**硬指标**：每3000字不超过1处。

典型模式：
```
不是A，而是B          → 「不是白天那种暗淡的银，而是从眼底深处透出来的光」
不是因为A，是因为B    → 「不是因为害怕，是因为力量在流失」
不是……而是……
```

**判断标准**：
- 在3.3万字中出现 ≥ 5处 → 🔴 过多
- 用于人物对话 → ✅ 可接受（口语化）
- 用于叙述 → ⚠️ 看上下文，合理描述可不修

### 6.2 AI副词（11个禁用词）

**硬指标**：每1000字不超过1处。全篇3万字建议 ≤ 15处。

| 副词 | 替代方案 |
|:---|:---|
| 突然 | 删掉或改为具体动作 |
| 猛地 | 直接描写动作（他回头→不修饰） |
| 瞬间 | 改为时间锚（一秒内/转眼） |
| 猛然 | 同「猛地」 |
| 不禁 | 删掉，直接描写 |
| 不由 | 删掉 |
| 骤然 | 避免 |
| 陡然 | 避免 |
| 忍不住 | 改为具体动作（他笑出声→直接写笑） |
| 忽然 | 同「突然」 |

**经验法则**：副词是写作的拐杖。能不用就不用。读者看的是动作和对话，不是修饰词。

### 6.3 叙事比喻（像…一样/仿佛/宛如）

**硬指标**：每3000字不超过1处。全篇3.3万字建议 ≤ 8处。

```
❌ 过度比喻：
  像活过来一样
  像沙堆一样崩塌
  像萤火虫一样飞散
  像白天一样
  像铁钳一样
  像破布一样
  像水泡一样
  像火焰一样

✅ 替代写法：
  改为直接描写（→ 符文发光，线条里流过银光）
  改为动词（→ 城堡崩塌，不是「像沙堆一样崩塌」）
```

**原则**：比喻用在关键的意象上（1-2处/篇），日常描写不要用。

### 6.4 全知视角泄露

**硬指标**：每2000字不超过1处。

常见模式（17种）：
```
「他记得」「她记得」「他想起」「她想起」
「他脑子里」「她脑子里」「他回忆」「她回忆」
「他知道」「她知道」「他意识到」「她意识到」
「他明白」「她明白」「他feel到」「她feel到」
```

**替代方案**：
| 原文 | 改为 |
|:---|:---|
| 他记得这个词…… | 「这个词……」他喃喃。 |
| 她想起母亲。 | 她摸着徽章，手指停在那个符号上。 |
| 这句话在她脑子里回响。 | （删掉，通过表情/动作暗示） |
| 他意识到自己错了。 | 他的手垂下来，什么也没说。 |

**原则**：不要替角色说出他们的心理活动。通过**动作、对话、表情、生理反应**让读者自己推断。

### 6.5 叙事者总结心理

禁止模式（8种）：
```
「他沉默了」→ 改为「他没说话」
「她脸色变了」→ 改为具体描写（脸白/手抖/嘴唇发青）
「他想了很多」→ 改为具体回忆片段
```

### 6.6 时间锚违规

禁止模式（4种）：
```
「与此同时」→ 删掉
「同一时间」→ 删掉
「就在这时」→ 最多1-2次/篇
「正在这时」→ 最多1-2次/篇
```

### 6.7 叙事过渡

**硬指标**：时间跳跃类过渡（第二天一早/半小时后/三天后）每3000字不超过1次。

合理使用：用三次以上提示节奏太赶。短故事中 < 3次可接受。

### 6.8 场景跳转

**硬指标**：同一段落内不能出现两个不同场景。

```
❌ 错误：同一段内场景跳转
  办公室→沈家别墅     → 必须分段+过渡句
  战斗现场→回忆片段   → 必须分段+过渡标记

✅ 正确做法：
  每个场景必须单独成段
  场景切换前加过渡句（「与此同时，在另一边……」）
```

## 第七章 对话格式（S8）

**权重**: 辅助参考

### 7.1 引号配对

**硬指标**：左引号数量 = 右引号数量。

大陆网文使用**双引号**（弯引号 `\u201c\u201d` 或ASCII直引号 `\u0022`），禁止使用直角引号 `「」`（日文/繁中用法）。

常见错误：
- 左引号多/右引号少 → 找落在段尾没闭合的引号
- 中间引号方向反 → `，」→「` 中间说话人的标记方向错了
- 英文省略号 `…` 替代中文 `……`

### 7.2 对话出现频率

每章至少出现对话。全篇不能有连续3段无对话的纯叙事。

### 7.3 过短对话片段

引号内仅1-3字的对话，可能造成碎片感。

判断标准：
- 如果是有力的命令/回应（「滚。」「走。」「服了。」）→ ✅ 可接受
- 如果是没意义的填充（「嗯。」「哦。」「好。」）→ ⚠️ 减少
- 如果连续5个以上短对话 → ⚠️ 需要加动作/表情补足

## 第八章 文字层（S9）

**权重**: 辅助参考

### 8.1 缺字检测（12种常见模式）

| 模式 | 检测规则 | 示例 |
|:---|:---|:---|
| 缺「最」→后一 | `后一` 但不属于 `最后/后一次/后一天/后世/后年/后代/后一刻……` | 「后一」→「**最**后一」 |
| 缺「如果」→果 | 孤立的 `果` | 「果你不在」→「**如**果你不在」 |
| 缺「阳光」→阳 | 孤立的 `阳`后面跟 `照/光/太影/明` | 「阳照」→「**阳光**照」或「**太阳**照」 |
| 缺「时间」→间 | 孤立的 `间` | 视上下文 |

**⚠️ 注意误报**：「阳光」已经是正确写法，不是缺字。「然后一扯」中的「后一」是「然后」的一部分，不是缺「最」。

### 8.2 标点检测

| 问题 | 检测 | 修复 |
|:---|:---|:---|
| 孤立引号 | 左右引号数量不等 | 找到缺的那个 |
| 英文省略号 | `...` → `……` | 替换 |
| 重复标点 | `！！` `？？` `。。` | 只保留一个或改为 `！` `？` |
| 多余空格 | 句中空格 | 删掉 |
| 连字符误用 | `——`用成 `-` 或 `—` 不配对 | 改成 `——` |

### 8.3 命名规范

| 规则 | 示例 |
|:---|:---|
| 职业标签直接写 | ❌「工头周」→ ✅「周工头」或「老周」 |
| 关系标签直接写 | ❌「陈妻」→ ✅「陈天华的妻子」 |
| 外号/昵称一致性 | 同一角色全篇外号一致 |

## 第十一章 长篇单章 vs 短故事检测区分

### 11.1 核心区别

| 维度 | 短故事 | 长篇单章 |
|:---|:---|:---|
| 字数 | 全篇3-15万字 | 每章2000-3000字 |
| 章节数 | 5-30章 | ≥100章 |
| 检测工具 | ss-check（9模块） | wn-check（17模块）+ detect_truth |
| 字数阈值 | 2000-3000字 | 2000-3000字 |
| 对话比 | ≥40% | 按章节类型判断，不机械追40% |
| 钩子 | 每章必须有 | 每章必须有 |

### 11.2 短故事检测时的已知盲区

| 盲区 | 表现 | 补偿方法 |
|:---|:---|:---|
| S1/S2假阳性 | 30K全篇合并为1章时S1/S2报告失真 | 信任S3/S4/S5，手工判断前3章 |
| 对话比偏低 | 合并文件后分割符计入非对话统计 | 手工逐章核实 |
| 意象式钩子漏检 | 「月亮在流血」类预言型钩子无关键词 | 人工读时注意 |
| 短对话误判 | 「滚。」「走。」是力量型回应非碎片 | 看上下文判断 |

### 11.3 工具扫不到的7类问题（必须人读）

1. **场景跳转断裂**：同一段内两个不同场景
2. **结尾视角混乱**：最后几行突然切视角
3. **冒号代替引号**：`她推开门:说话` 格式
4. **对话归属缺失**：连续对话中某行无说话人
5. **跨段引号分裂**：一句对话被拆成两段引号
6. **语义缺字**：后→最后、果→如果、你他会说吗→你觉得他会说吗
7. **章节标题缺失**：首段不是 `第X章` 格式
