## 一、书名创作方法（番茄官方方法论）

### 关键词四维度

从以下维度提取3-5个核心关键词，重点是突出差异化看点：

| 维度 | 说明 | 示例 |
|:-----|:-----|:-----|
| 身份词 | 点明主角是谁 | 千金/神医/保安/赘婿/女王 |
| 动作词 | 核心事件/冲突 | 归来/重生/闪婚/替嫁/被裁员/被出轨 |
| 情感词 | 情绪基调 | 爽/甜/治愈/虐/燃/怒/遗憾 |
| 场景词 | 背景场景 | 都市/古代/校园/职场/末世 |

### 爆款书名五类型

| 类型 | 核心公式 | 写法要点 | 示例 |
|:-----|:---------|:---------|:-----|
| 悬念好奇型 | 制造「信息缺口」→读者追问「为什么？」 | 用反常信息/身份错位/异常行动制造疑惑 | 《只剩七天寿命她不忍了》 |
| 冲突反差型 | 低位身份+顶配实力/马甲身份 | 身份能力鸿沟越大，爽感越强 | 《发配边关，罪妻开荒养出战神》 |
| 情绪直给型 | 口语化+极致情绪词 | 击中目标用户情绪痛点，用日常口语最有冲击力的词汇 | 《下山后我横扫一切》《我掀桌了年夜饭》 |
| 文艺诗意型 | 诗词意境+象征比喻 | 借助诗词提升格调，但必须与内容调性适配 | 《红糖姜汁》《何须相守到白头》 |
| 引经据典型 | 经典文化符号 | 借助经典文化符号的认知度，降低理解成本 | 《亲爱的维多利亚港》 |

### 自检清单

- [ ] 字数≤30字（平台限制）
- [ ] 包含四要素：人物关系、亮点爆点、关键词、共情
- [ ] 无震惊体/低俗暗示/语病/生僻词/题文不符
- [ ] 差异化：与同类排名前10-15个书名不高度同质化

## 二、简介7条共同规律（千面分析）

### 1. 字数
纯文本简介 **150-200字** 为黄金区间。300字以上偏长，适合带标签的新趋势作品；短篇爽文更适合精悍路线。

### 2. 段落
- 1段连续块 或 2-4短段 皆可
- **禁用 `***` 分隔线**——爆款全都不用
- 爆款格式样本：
  ```
  前世惨死段落（2-3句）
  重生觉醒段落（2-3句）  
  复仇爽感递进（1-2句）
  冷感金句收尾（1句）
  ```

### 3. 开头第一句
全部以**前世惨死/被背叛场景直接切入**，不铺垫、不介绍背景：
- "她死过一次。死在丈夫和闺蜜的合谋里。"
- "六年感情，他搂着新欢，跟她提分手。"
- 用「死过一次」「含恨而终」等强动词开场

### 4. 钩子
- 用省略号制造悬停（"他跪在她面前……"）
- 用情感翻转（从爱到冷）吸引读者
- **不透露复仇手段**（只写结果如"产业易主"，不写怎么做到的）

### 5. 结尾
- 一律以**冷感金句**或**不可逆结局画面**收尾
- 例："不恨。你还不配。""她没回头。"

### 6. 符号规则
- 无 Emoji
- 无书名号（介绍其他作品时除外）
- 不用 `***` 或 `---` 分隔线
- 用中文引号包裹角色对话

### 7. 禁用内容
- 简介内不写支线角色（温如兰、苏棠等不上简介）
- 不剧透关键反转的具体方法
- 不写"这是一篇讲……的故事"这类说教句

## 我们的简介模板（已验证可用格式）

```
沈柠晞死过一次。死在丈夫顾廷深和闺蜜林诗雨的合谋里——家破人亡，含恨而终。

再睁眼，她回到婚礼当天。红毯尽头，顾廷深笑着等她。她扯下头纱，转身就走。他追上来拉她，她低头看着他的手："松开。我嫌脏。"

这一世，她不嫁了。不哭不闹不纠缠，她冷静得像一把刀。顾廷深以为她只是在赌气。直到产业易主，证据递进法院，他跪在她面前。

沈柠晞低头看他，语气淡得像在说天气："不恨。你还不配。"
```
