## 课堂阅读工作流

### 获取方法

番茄作家课堂页面是 SPA（React），浏览器翻页不生效。替代方案：
1. 用 Tavily 搜索 `site:fanqienovel.com/writer/zone/article 作家课堂` 找到文章ID
2. 直接导航到 `https://fanqienovel.com/writer/zone/article/{article_id}`

### 高级技巧：直接提取文章URL

当浏览器翻页失效时，在浏览器控制台执行：
```javascript
var arts = document.querySelectorAll('a');
var result = [];
for (var i = 0; i < arts.length; i++) {
  var t = arts[i].textContent.trim();
  if (t.length > 5 && t.indexOf('京') === -1 && t.indexOf('www.') === -1 && t.indexOf('@') === -1) {
    result.push({text: t.substring(0,30), href: arts[i].href.substring(0,80)});
  }
}
JSON.stringify(result);
```
安全链接中的 targetUrl 参数包含真实 article ID（如 `...targetUrl=https%3A%2F%2Ffanqienovel.com%2Fwriter%2Fzone%2Farticle%2F7665547170958802968...`）。

### 推荐阅读模式

**批量阅读法**（本会话已验证）：
1. 一次读5篇，每篇用 browser_navigate 直接加载
2. 读完后给用户总结（每篇3-5行+总体提炼）
3. 用户说"消化吸收"后，将新规则更新到 SKILL.md 铁律速查表
4. 更新 子任务前缀，确保下次派任务时自动带上新规则
5. 更新 团队落地映射.md，记录每篇文章的精华→角色→文件位置
6. 循环：继续下一批5篇

**判断标准**：
- 只读"作家课堂"类文章（官方课堂/新手专区/写作技巧），跳过活动通知/违规公告/活动征文
- 优先阅读阅读量高（>1w）和标题含"短故事"的文章
- 和团队方向（西方题材/大女主复仇/爽文）强相关的优先

## 一、改编书名创作法（源自「从网文到短剧：设置改编书名」）

### 核心公式
锁定核心卖点 → 提炼关键词 → 匹配取名方法 → 生成改编书名

### 关键词四维度
| 维度 | 说明 | 示例 |
|:-----|:-----|:-----|
| 身份词 | 主角是谁 | 千金/神医/保安/职员 |
| 动作词 | 核心事件 | 归来/重生/闪婚/下山/被裁员 |
| 情感词 | 情绪基调 | 爽/甜/治愈/虐/燃/怒 |
| 场景词 | 背景场景 | 都市/古代/校园/职场 |

### 爆款剧名五类型

| 类型 | 核心公式 | 示例 |
|:-----|:---------|:-----|
| 悬念好奇型 | 制造「信息缺口」→读者追问「为什么？」 | 《只剩七天寿命她不忍了》 |
| 冲突反差型 | 低位身份+顶配实力/马甲 | 《发配边关，罪妻开荒养出战神》 |
| 情绪直给型 | 口语化+极致情绪词 | 《下山后我横扫一切》《我掀桌了年夜饭》 |
| 文艺诗意型 | 诗词意境+象征比喻 | 《红糖姜汁》《何须相守到白头》 |
| 引经据典型 | 经典文化符号 | 《亲爱的维多利亚港》 |

## 二、主线架构与起承转合（源自「打破剧情散架」）

### 主线句公式
> 谁+在什么困境下+为了达成什么目标+必须对抗什么力量+最终获得或失去什么

### 起承转合时长分配

| 阶段 | 占比 | 功能 | 关键要求 |
|:-----|:----:|:-----|:---------|
| 起 | 10-15% | 钩住读者 | 交代主角+困境+一个悬念/眼前危机 |
| 承 | 50-60% | 持续加码 | 4个阶段性高潮，每个高潮=目标→阻碍→代价→收获→新问题 |
| 转 | 15-20% | 全局升级 | 必须有伏笔铺垫（物件类/身体特征类/言行类/事件类） |
| 合 | 10-15% | 兑现承诺 | 解决核心矛盾+回应开头悬念+完成主角成长 |

### 四大常见问题及解法

| 问题 | 解法 |
|:-----|:-----|
| 开局悬念太多 | 保留1个大悬念+1个眼前危机 |
| 铺垫只有信息没事件 | 把设定放进冲突场景里带出 |
| 中段无阶段高潮 | 每隔几章安排一次局势明显改变的事件 |
| 结局只打架不回收 | 预留专门的「伏笔回收篇幅」 |

## 三、世情爽文五大避坑指南（源自第十三期作家课堂）

### 避坑一：导语切入点需具象
**核心原则**：切入点 = 具体事件 + 核心利益关联 + 情绪锚点
- ❌ 「我从小被偏心」→ ✅ 「每年除夕，婆婆都只给我一碗白米饭」
- ❌ 「婆家一直欺负我」→ ✅ 「热水器显示温度：22℃」
- **量化矛盾**：用可量化不公替代泛化描述

### 避坑二：主线聚焦
- 始终围绕「核心利益被侵占→觉醒反击→自我成长」展开
- 每一条支线必须是核心矛盾的升级或补充
- 聚焦1-2个核心冲突对象

### 避坑三：冲突爆发需有积累
- 冲突爆发需要「伏笔→积累→引爆」完整过程
- 设置3个左右隐忍细节，铺垫情绪临界点
- 引爆点必须是触及核心利益的最后一根稻草

### 避坑四：冲突递进升级
- 阶梯式升级：小事积累→大事爆发→核心利益对抗→人格尊严对抗
- 用具体行动替代口头争吵（收集证据、法律维权、经济独立）

### 避坑五：爽点讲逻辑
- 主角反击要有隐忍理由+底气+手段+代价
- 反派有真实动机+人性弱点，不是纯粹坏
- 爽感最好指向主角的自我成长，不只是报复

## 四、言情向爆款创作共性（源自第二十期作家课堂）

### 甜宠向
- 大女主清醒独立，掌握关系主动权
- 男主提供情绪价值，百分百偏爱与坚定选择
- 经典套路+反套路破局：配角跳出脸谱化，婆婆帮儿媳不帮儿子
- 用小事发糖，发糖与女主事业/打脸爽点深度绑定
- 人设公式：1个核心特质+1个反差行为

### 虐爽向
- 利用信息差制造「读者先知，主角后知」的拉扯感
- 经典题材微创新赋能，局部反转或叠加
- 高密度反转推进剧情，章章有钩子

**万能架构**：
1. 错位认知 → 2. 极致的守护/背叛 → 3. 真相揭晓破局 → 4. 圆满逆袭反击

### 人设创作要点
- 微醺女主不是反应慢，是情绪延迟但底线极硬
- 复仇女主不是疯批，是受过伤所以只信事实
- 反派坏得有层次，有逻辑动机（嫉妒/不甘/童年创伤/被挑唆）

## 五、宫斗宅斗创作技巧（源自第十六期作家课堂）

（虽非主攻方向，但爽点设计思路通用）

### 爽点设计
- **高位类**：爽点间隔不超过300字，用阶级差/权力差直接碾压
- **底层逆袭类**：侧重智斗，将计就计/借刀杀人替代蛮力

### 人设塑造
- 女主明确核心标签（清醒独美/黑莲花/扮猪吃虎）
- 加入小反差（高冷掌权者偏爱甜食、底层复仇者性格温柔）

### 设定运用
- 外挂/系统/弹幕能降低权谋门槛
- 重生文：开篇直接点明前世关键遗憾+今生复仇目标

## 六、代入感六大核心技巧（源自「从本质到方法，塑造代入感」）

### 本质
> 「主角就是我」——读者通过主角的视角体验故事

### 六大支柱

| 支柱 | 核心 | 操作方法 |
|:-----|:-----|:---------|
| ① 基础信息标签化 | 读者先认知主角，再认知世界 | 百十来个字概括：男女/高矮胖瘦/特征 |
| ② 具体化可视化 | 描述到读者能想象 | 具体场景+熟悉感（高考分手/医院走廊） |
| ③ 认知共鸣 | 主角的选择=读者会做的选择 | 「我也会这样」「就该这么做」 |
| ④ 情绪共鸣 | 以天然情感纽带快速带动情绪 | 亲情/不公/弱势方被欺负 |
| ⑤ 欲望好奇心 | 满足读者「不劳而获/高人一等」的欲望 | 期待感：憋屈→扬眉吐气 |
| ⑥ 五感代入 | 视觉/听觉/嗅觉/触觉/味觉 | 潮湿的短袖黏在后背、医院消毒水的味道 |

### 增强代入感的五种方式
1. 熟悉感（高考分手/医院走廊等共通场景）
2. 标签（主角身份快速定位）
3. 冲突的紧迫性（时间压力/生存压力）
4. 接地气（不土，但贴近真实生活）
5. 减少「了」字和转折词的使用

### 网络小说本质
> 满足读者的「欲望」——不劳而获、高人一等、权势地位。
> 基础欲望 = 读者本身存在的欲望（爽文）
> 主动欲望 = 作者通过剧情制造的期待感（憋屈→扬眉吐气）

## 七、作品质感提升（源自「五步让作品质感飙升」）

### 核心观点
- 写作是探索，不是解题。大纲和人设是辅助工具，不是枷锁
- 过度准备压抑灵感——先动笔写，再在过程中梳理大纲
- 人物扁平化 = 缺乏「撞击感」和背景故事
- 用后台数据（读完率/跟读率）指导优化

### 人物塑造
- 优秀人设推动剧情发展，及格人设为剧情服务，不合格人设拖垮整篇
- 好的人设需要背景故事——当人物有了自己的故事，就容易立住脚

## 八、推荐验证期规则（源自「推荐验证期规则全指南」）

（短故事不走推荐验证流程，但了解无妨）

| 条件 | 主动申请 | 平台自动 |
|:-----|:---------|:---------|
| 字数 | 8万字+ | 15万字+ |
| 签约 | 已签约 | 已签约 |
| 封面 | 非模版封面 | 非模版封面 |
| 更新 | 连续3日≥4000字 | — |

- 连载作品最多3次评估机会，完结仅1次
- 3次不通过 → 永久不能进入推荐验证
- 流量不好的核心：封面、书名、简介是门面

## 九、对团队铁律的补充建议

### 可融入快刀铁律的点
1. **量化矛盾**：导语/冲突场景用「具体可量化的不公」替代泛化描述（一碗白米饭 > 婆婆偏心）
2. **阶梯式冲突升级**：小事积累→大事爆发→核心利益对抗→人格尊严对抗
3. **虐爽向万能架构**：错位认知→极致的守护/背叛→真相揭晓破局→圆满逆袭反击
4. **代入感欲望维度**：网络小说本质是满足读者「不劳而获/高人一等/权势地位」的欲望

### 可融入开锋铁律的点
1. **改编书名五类型**：悬念好奇型/冲突反差型/情绪直给型/文艺诗意型/引经据典型
2. **关键词四维度**：身份词/动作词/情感词/场景词

### 可融入节律铁律的点
1. **起承转合比例**：起10-15%/承50-60%/转15-20%/合10-15%
2. **承阶段4个高潮**：每个高潮=目标→阻碍→代价→收获→新问题
