# 角色声音设计体系

> 来源：番茄爆款创作团实战产出·2026-07-25
> 用户要求：「小说出现的人物性格特点明显。让读者看到某个人物就知道这个人要怎么说话。」

## 核心方法

每个主要角色必须同时拥有：
- **说话风格**（用2字词概括，如寒刃/暖刃/铁秤/油刀）
- **反差标签**（一句反差宣言，如「穿Armani开枪的女人」）
- **说话风格详细描写**（语速、用词习惯、情绪表达方式、口头禅）

## 说话风格标签设计模板

| 维度 | 说明 | 示例 |
|:-----|:-----|:-----|
| 风格名 | 2字词概括，可对比的两字（寒/暖、铁/油、钢/钝） | 寒刃、暖刃、铁秤 |
| 语速 | 快/慢/变化 | 语速偏慢，句子极短 |
| 用词 | 是否带方言/行业术语/古语 | 带街头腔调，偶尔粤语 |
| 情绪表达 | 愤怒时怎么做？紧张时怎么做？ | 愤怒时声音更轻 |
| 口头禅 | 标志性短句 | 「等着。」「成交。」「你猜。」 |

## 八大说话风格词库（实战产出）

| 风格名 | 适合角色 | 核心特征 |
|:-------|:---------|:---------|
| 寒刃 | 冷面女主 | 语速慢、句子短、愤怒时更轻。每句话要么是命令要么是结论，从不解释 |
| 暖刃 | 忠犬盟友 | 话快、带街头腔、关心用行动替代（递豆浆不说话）。紧张时重复问同一个问题 |
| 铁秤 | 元老长辈 | 咬字重、爱用歇后语和江湖切口。称呼变化=态度变化：大小姐→清瑶→龙头 |
| 油刀 | 笑眯眯的情报头子 | 广东腔、打哈哈绕回来、笑里藏刀。情报永远轻描淡写：「哦，那个啊，我知道一点」 |
| 绸缎裹铁 | 优雅反派 | 用词好、威胁带着笑、句末混外文（capisce?）。沉默越长越危险 |
| 钢尺 | 专业人士 | 不寒暄、开口就重点、谈判习惯性抛条件：「你帮我，我帮你」 |
| 钝刀 | 粗人反派 | 声大、爱拍桌、文化不高爱装懂（滥用成语）。心虚时音量更高（虚张声势） |
| 抹油 | 滑头中间人 | 永远笑、永远不表态、每句话留三分余地：「这个嘛……」「您看这样行不行……」 |

## 反差标签设计原则

反差标签 = [一个出乎意料的外部包装] + [内在本质]

公式：「穿X的Y」/「有X的Y」/「用X的Y」

| 角色 | 反差标签 | 结构拆解 |
|:-----|:---------|:---------|
| 冷面女主 | 穿Armani开枪的女人 | 精英外表×狠手段 |
| 忠犬盟友 | 有虎牙的杀手 | 可爱外表×干脏活 |
| 优雅反派 | 用钢笔杀人的刽子手 | 文雅外表×血腥事实 |
| 情报头子 | 笑面佛的账本 | 人畜无害×掌握所有人的把柄 |
| 专业人士 | 法律的刀鞘 | 执法者×在法律边缘游走 |
| 元老长辈 | 念旧的老刀 | 规矩至上×为大局打破规矩 |
| 粗人反派 | 吃两边的狼 | 执法堂主×收黑钱卖兄弟 |
| 滑头中间人 | 体面人的脏手套 | 社区领袖×洗最多的钱 |

## 对话中体现人物性格的实战技巧

### 1. 称呼变化标记关系进度
陈鹤亭对沈清瑶的称呼变化：
- 大小姐 → 客气、疏远、公事公办
- 清瑶 → 软化、开始接受
- 龙头 → 彻底归心、臣服

### 2. 语速和用词暴露情绪
- 平时语速慢的人突然加快 = 紧张/失控
- 平时暴躁的人突然沉默 = 愤怒到极点
- 平时文雅的人开始说脏话 = 被逼到绝境

### 3. 对话长度暴露权力关系
- 上位者话少（命令/结论）
- 下位者话多（解释/辩解）
- 心虚者话多（试图说服）
- 自信者话少（不需要证明）

### 4. 特殊语言标记
- 角色A：习惯句末加「对吧？」
- 角色B：习惯用反问「你确定？」
- 角色C：习惯用「啧」开头
- 角色D：焦虑时会重复上一句结尾的三个字

## 写前必检新增项

在人物设定阶段，完成以下检查：
7. ✅ **说话风格标签**：每个主要角色是否有2字说话风格标签？
8. ✅ **反差标签**：是否有反差点？
9. ✅ **说话差异化**：合上角色名看对话，能否分出谁在说话？
