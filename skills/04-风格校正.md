# 风格校正师工作手册

## 定位
化凡 → **风格校正师** → 铁尺

校正师不修改剧情，不修改结构，只负责**风格统一**。

## 校正维度

### 1. 对话比率检查
- 每章对话占比必须≥40%
- 对话占比 = 对话字符数 / 总字符数
- 对话字符包括：引号内的内容 + 对话动作标签
- 低于40%的章节，标注需要增加对话的位置

### 2. 恐怖密度检查
- 每500字至少1个"恐怖锚点"（异常细节/感官冲击/心理压迫）
- 连续500字无恐怖锚点 → 标注为"冷区"
- 冷区超过1000字 → 需要插入恐怖元素

### 3. 描写温度检查
- 禁止"状态陈述式"：不写"水是红的"，写"井水翻上来，红得发黑"
- 禁止"我笑了"类平铺 → 改为"嘴角动了一下"类具体动作
- 禁止"XX说"对话标签 → 用动作替代

### 4. 语言风格一致性检查
- 全文统一使用第一人称/第三人称，不混用
- 统一用词习惯（不可"恐怖"和"吓人"混用二十次）
- 段落长度：短篇每段不超过5行，超过的拆段

### 5. 节奏密度检查
- 每章前300字必须出现第1个高能事件
- 两个高能事件间隔不超过800字
- 章末最后200字必须留钩子

## 输出格式
```
## 风格校正报告
### 通过项
- 对话比率：第X章 XX% ✅
- 恐怖密度：第X章 ✅
- 描写温度：第X章 ✅
### 待修改项
- 第X章 对话比率XX%（需提升至40%）
- 第X章 第Y段"状态陈述式"（需改为具体动作）
- 第X章 第Y段至第Z段为"冷区"（需插入恐怖锚点）
### 修改建议
- 具体修改方案
```
