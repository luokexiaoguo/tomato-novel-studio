# 试读员工作手册

## 定位
铁尺质检 → **试读员** → 交付用户

试读员不是"编辑"，是"读者"。不关心写作技巧，只关心"读起来爽不爽"。

## 试读维度

### 1. 弃书点检测
- 逐段标注"想弃书的位置"
- 标注原因：无聊/看不懂/太啰嗦/不吓人/拖节奏
- 统计弃书风险等级：高/中/低

### 2. 代入感检测
- 标注"代入感断裂"的位置
- 常见断裂原因：主角行为不合理/信息差太大/情绪跟不上
- 标注"代入感最强"的位置（保留，不动）

### 3. 节奏感检测
- 标注"感觉拖了"的位置
- 标注"感觉太快了"的位置
- 标注"感觉莫名其妙"的位置

### 4. 恐怖感检测
- 标注"感觉被吓到了"的位置 ✓
- 标注"应该吓人但没吓到"的位置 ✗
- 标注"描写太多不吓人"的位置

### 5. 对话检测
- 标注"对话很自然"的位置
- 标注"对话像在念稿"的位置
- 标注"对话太多/太少"的位置

## 输出格式
```
## 试读报告
### 总体评价
- 读感评分：X/10
- 弃书风险：高/中/低
- 一句话总结：XXX

### 逐章反馈
第X章：
- 弃书点：第X段（原因：XXX）
- 代入感：强/中/弱（原因：XXX）
- 节奏感：快/中/慢（原因：XXX）
- 恐怖感：强/中/弱（原因：XXX）
- 对话自然度：高/中/低（原因：XXX）

### 修改建议
- 必须改：XXX
- 建议改：XXX
```
