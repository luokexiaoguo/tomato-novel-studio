# 角色说话指纹方法论

## 核心原则
**读者不看名字，只看对话，就能说出"这句是谁说的"。**

《鬼吹灯》教科书级示范：
- 胡八一：京腔贫嘴+部队腔，紧张时还能甩段子
- 王胖子：咋咋呼呼，"发财了！"，莽撞贪财
- Shirley杨：干脆专业，中英混着来，永远冷静
- 大金牙：市侩商人味，三句话不离生意

## 四维指纹模型

每个角色必须建立以下四个维度的说话指纹：

### 1. 口头禅/标志性用语
- 每个角色固定1-3个高频词或句式
- 例：胡八一"胖爷"、王胖子"发财了"、老刘"别往X看"
- 使用频率：每章至少出现1次，但不超过3次（避免机械重复）

### 2. 反应模式（同一件事，不同反应）
同一事件发生后，每个角色的第一反应必须不同：
- 技术流角色：先看设备/数据，嘴上说"没事"，手在抖
- 胆小角色：先喊"跑/卧槽"，但跑之前必须问"那是什么"
- 资料党角色：先翻手机/翻本子/找记录，蹦重磅信息不解释
- 预言者角色：只说警告，不说破："别往井里看"
- 例：看到井绳自己动——
  - 技术流：蹲下来看转轴，不说话
  - 胆小："卧槽卧槽卧槽，绳子它自己在转！"
  - 资料党："民国县志里记过一口井，每年七月十四绳子自己动。"
  - 预言者（不在场，之前说过）："别往井里看。"

### 3. 用词习惯
- 方言/地域色彩：东北腔（"这啥玩意啊"）、京腔（"您嘞"）、土话（"后生""娃"）
- 职业用语：摄影师（"快门""白平衡"）、博主（"兄弟们""老铁"）、研究员（"县志""文献"）
- 语域差异：书面的vs口语的、完整的vs破碎的、解释的vs警告的

### 4. 句式节奏
- 话多型：句子短密，一紧张就碎句连发
- 话少型：惜字如金，偶尔蹦一句重磅
- 分析型：句式完整，爱用"不是X，是Y"结构
- 预言型：半句留半句，用比喻不用直说

## 执行步骤

### Step 1：拆解对标作品角色
仿写师在拆解爆款时，必须新增"角色说话指纹"维度：
- 每个主要角色单独建档
- 摘录3-5句标志性台词（原句）
- 标注：口头禅/反应模式/用词习惯/句式节奏

### Step 2：建立本书角色指纹表
写手开工前，先输出"角色说话指纹表"：
| 角色 | 口头禅 | 面对异常的第一反应 | 用词习惯 | 句式节奏 | 记忆点台词 |
|---|---|---|---|---|---|
| 角色A | | | | | |
| 角色B | | | | | |

表必须过铁尺验收：**四维必须两两互斥**（A的口头禅不能是B的，A的反应模式不能是B的）

### Step 3：写作时强制应用
- 每段对话前，问自己：这句话像不像这个角色说的？
- 如果换个人名也能成立，说明指纹失效，重写
- 同一场景，尽量让每个角色都有一句符合自己指纹的反应

### Step 4：质检清单（铁尺新增维度）
- [ ] 每个角色是否有≥2个维度的指纹
- [ ] 四维是否两两互斥
- [ ] 遮名测试：把角色名涂掉，能否判断谁在说话？
- [ ] 口头禅是否每章1-3次（不过度）
- [ ] 同一事件的多人反应是否不同

## 常见失败模式
1. **全员冷静**：所有角色面对异常都是"分析型"，说话节奏趋同 → 必须让至少一个角色情绪外露
2. **全员胆怯**：所有角色都怕，读者找不到"稳定锚点" → 至少一个角色在恐惧中保持动作
3. **工具人化**：角色只是"剧情推进器"，说话功能化 → 每个角色要有与剧情无关的性格表现
4. **口头禅过载**：每句话都带口头禅 → 控制频率，关键场景才用

## 反例与正例对照
| 反例（失败） | 正例（成功） |
|---|---|
| "这村子不对。"陈坤说。"我也觉得。"我说。"查一下。"孟小恬说。 | "这村子不对。"陈坤往后缩。"卧槽，你们闻到没？""先看设备。"我蹲下来，"信号没断，说明不是物理干扰。""我查过县志——"孟小恬翻本子，"这村子1963年死过人。" |
| 三人反应：都沉默 | 三人反应：一个蹲下看设备，一个喊跑，一个翻本子 |
