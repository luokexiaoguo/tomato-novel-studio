# 仿写分析师工作手册

## 核心职责
拆解番茄悬疑爆款短故事，提取可复用的写作模板，供创作层直接使用。

## 拆解维度

### 1. 开篇结构拆解
- 第1句类型：必须是"背景陈述型"（如"周宇搬进这个小区已经一周了"）
- 禁止类型：对话开头（"这村子不干净"）、动作开头（"老刘熄了火"）
- 前300字事件密度：必须标注第几个字出现第一个异常
- 从日常到异常的转折速度：日常铺垫不超过3段

### 2. 对话模式拆解
- 对话占比：精确统计（%）
- 对话轮次：每段对话的来回次数（不超过4轮）
- 对话类型：信息推进型 / 情绪渲染型 / 氛围制造型
- 对话标签：必须全部用动作替代"XX说"

### 3. 叙事风格拆解
- 人称：第三人称
- 角色命名：有真实姓名（周宇/陈哥/李姐），不是"我/阿坤/小孟"
- 句子长度：平均每句不超过20字
- 修饰词数量：每100字不超过2个形容词/副词

### 4. 恐怖来源拆解
- 恐怖类型：日常物件异常 / 信息差 / 细思极恐 / 跳吓
- 禁止类型：环境渲染恐怖（雾/阴森/诡异）、神秘台词恐怖
- 恐怖锚点：每500字至少1个，必须来自具体事物
